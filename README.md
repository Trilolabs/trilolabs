# Trilolabs

Marketing site for Trilolabs — Next.js App Router, content in `app/content.js`, static assets under `public/brand` and `public/media`.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — run production server locally

## Structure

- `app/` — routes, components, global styles
- `app/content.js` — copy and media paths
- `public/brand/` — logo, favicon, OG image
- `public/media/` — photography and section artwork
